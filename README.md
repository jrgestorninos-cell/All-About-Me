# All About Me hehe

## Description

All About Me is a collection of three creative and technology-related activities that showcase my skills in graphic design, personal branding, visual communication, and technology-based problem-solving. Each activity demonstrates how design principles and digital tools can be used to effectively communicate ideas and address real-world problems.

## Activity 1: Presentation Design Principle

This activity focuses on applying presentation design principles to create a promotional poster for a hypothetical event offering free coffee. The poster demonstrates the use of layout, typography, color, visual hierarchy, and other design elements to create an attractive and engaging event announcement.

## Activity 3: Social Media Infographics and Mini Project Documentation

This activity focuses on visual communication and technology-based problem-solving by addressing a real-world issue: long waiting times in clinics and hospitals.

The first part involves creating a visually engaging social media infographic that presents and simplifies the identified problem using relevant information, data, and visual elements. The infographic aims to make the issue easy to understand while effectively communicating its impact.

The second part involves creating a mini project documentation report proposing an IT- or technology-enabled solution to the identified problem. The proposed solution is a digital queue management system, which aims to improve the organization of patient queues and help reduce waiting times in clinics and hospitals.
