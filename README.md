# All About Me

## 📌 Description

Hello! My name is **John Roel G. Estorninos**. I created this repository as a digital portfolio to showcase my activities, projects, and learnings throughout the course. It contains seven activities that demonstrate my creativity, skills, and exploration of different digital tools and technologies.

Through these activities, I gained experience in presentation design, personal branding, visual communication, productivity tools, artificial intelligence, and website development. I also learned how technology can be used to communicate ideas, improve processes, and develop solutions to real-world problems.

This portfolio represents my learning journey, creativity, and continuous development in using technology for both academic and practical applications.

## Activity 3: Social Media Infographics and Mini Project Documentation

This activity focuses on **visual communication and technology-based problem-solving** by addressing a real-world issue: **long waiting times in clinics and hospitals**.

The first part involves creating a visually engaging **social media infographic** that presents and simplifies the identified problem using relevant information, data, and visual elements. The infographic aims to make the issue easy to understand while effectively communicating its impact.

The second part involves creating a **mini project documentation report** proposing an IT- or technology-enabled solution to the identified problem. The proposed solution is a **digital queue management system**, which aims to improve the organization of patient queues and help reduce waiting times in clinics and hospitals.

## Activity 5: AI Tools Activity

This activity explores the use of **Artificial Intelligence (AI), particularly ChatGPT, in developing and improving program flowcharts**.

I used ChatGPT to generate two versions of a program flow: an initial version and an improved version. The two outputs were then compared to identify the changes, improvements, and differences in their structure and logical flow.

This activity demonstrates how AI can assist in developing program logic, identifying possible improvements, and making processes more organized and efficient.

## Activity 7: Resume Generating

This activity explores the use of **Artificial Intelligence in professional document creation**, specifically in developing a professional resume.

I used two AI platforms, **ChatGPT and Claude AI**, to generate a resume based on my personal information, educational background, and qualifications. After generating both resumes, I compared their outputs in terms of content, organization, presentation, and overall quality.

This activity demonstrates how different AI platforms can produce different results even when given similar instructions. It also emphasizes the importance of reviewing, evaluating, and refining AI-generated content to ensure accuracy and professionalism.
